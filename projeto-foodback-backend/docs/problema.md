# Problema Identificado

Atualmente, muitas **empresas descartam alimentos** que ainda estão próprios para consumo por falta de logística e comunicação eficiente.

Enquanto isso, as **ONGs enfrentam dificuldade para manter doações constantes** e previsíveis, o que prejudica o planejamento e a distribuição.

**Consequências:**
- Desperdício de alimentos
- Falta de recursos para quem precisa
