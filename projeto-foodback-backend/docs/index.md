# FoodBack

**FoodBack** é uma plataforma digital que conecta **empresas que possuem alimentos excedentes** com **ONGs que distribuem alimentos** para pessoas em situação de vulnerabilidade.

Nosso propósito é simples:  
**transformar o desperdício em solidariedade**, garantindo que cada alimento tenha um destino melhor.
